# 0148 - 为 KEY3 的 +7cm 目标增加末段制动

## 修改原因

KEY3 日志显示钢球已短暂到达 `X=7.0 cm`，但没有末段捕获制动，随后回滚至约 `X=2.4 cm`。控制器持续叠加负向静摩擦倾角至 `-155 pulse`，实际电机反馈达到 `RAW=-5952`，接近已知机械极限 `RAW=-5974`，仍无法重新推动钢球。

## 修改内容

- KEY3 在距离 `+7 cm` 小于 `3 cm`、接近速度超过 `20 cm/s` 时启用反向制动。
- KEY3 制动倾角范围为 `30~60 pulse`，独立于中心点与 KEY1。
- KEY3 反向制动生效后，将累积的静摩擦倾角复位为初始 `35 pulse`，防止制动结束后恢复大倾角而再次冲过目标。
- KEY1 和 KEY2 的控制参数及制动路径未修改。

## 验证

- Keil 全量编译：`0 Error(s), 0 Warning(s)`。
