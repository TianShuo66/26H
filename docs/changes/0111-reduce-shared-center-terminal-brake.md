# 0111 - 降低 0 cm 与 -5 cm 的共用末段反制动

## 现象

- -5 cm 阶段在距目标约 `1.9 cm`、估计速度约 `8.9 cm/s` 时触发 `-70 pulse` 反制动。
- 钢球在约 `-4.4 cm` 提前反向，说明共享的末段反制动力过大。

## 修改

- `0 cm` 与 `-5 cm` 共用的终端反制动基础值从 `35` 降至 `20 pulse`。
- 速度增益从 `2` 降至 `1 pulse/(0.1 cm/s)`，最大反制动从 `70` 降至 `45 pulse`。
- `+5 cm` 使用独立的原有参数，保持不变。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过，`0 Error(s), 0 Warning(s)`。
