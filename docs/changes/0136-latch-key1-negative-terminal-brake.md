# 0136 - 锁存 KEY1 负向终点制动

## 修改原因

负向制动已将钢球送至 `-4.9 cm`，但钢球越过目标后位置误差变号，原控制立即取消制动，导致钢球回弹到 `-3.0 cm` 并在五秒时超时。

## 修改内容

- 为 KEY1 的 `+5 -> -5 cm` 段增加独立的负向终点制动锁存。
- 制动触发后，即使位置跨过 `-5 cm`，也持续施加反向制动，直到估计速度降至零或转正。
- 制动释放后仍使用现有的负向低速闭环与静摩擦补偿靠近目标。
- `+5 cm` 目标和其他按键控制保持不变。

## 验证

- Keil 全量编译：`0 Error(s), 0 Warning(s)`。
