# 0143 - 按速度进入回中心微调

## 修改原因

回中心测试中，钢球在 `X=+0.7 cm`、速度约 `-14.8 cm/s` 时进入微调区，倾角从 `-57 pulse` 被限制到 `-18 pulse`，制动显著减弱，钢球越过中心摆至约 `-4.3 cm`。

## 修改内容

- 新增中心微调进入速度门限 `30 cm/s`。
- 仅当位置位于中心 `±1 cm` 且估计速度不超过门限时，才启用微调倾角限制。
- 已启用微调时，若速度再次超过门限，立即退出微调并恢复速度环制动。
- KEY1 的 `0 -> +5 -> 负向目标` 控制逻辑未修改。

## 验证

- Keil 全量编译：`0 Error(s), 0 Warning(s)`。
