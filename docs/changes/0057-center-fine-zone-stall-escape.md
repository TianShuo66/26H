# 0057 - 修复中心点 1.5 厘米微调卡滞

日期：2026-08-01

## 实测问题

回中心日志在 `X=-1.5 cm` 持续停滞：

- 已进入中心点最后 `1.5 cm` 微调区；
- `TILT_REF` 长时间只有 `-14 ~ -18 pulse`；
- 观测速度约 `-1.3 cm/s`，高于原来 `0.8 cm/s` 的静摩擦补偿门限；
- 因此 `15 pulse` 的静摩擦补偿没有触发，钢球不能继续朝中心移动。

## 修改内容

- 中心点微调静摩擦倾角：`15` 提高到 `25 pulse`。
- 中心点微调静摩擦补偿速度门限：`0.8 cm/s` 提高到 `2.0 cm/s`。

补偿仅在距中心超过 `0.7 cm` 时生效；进入中心附近后，仍使用原有的小倾角闭环微调。

## 未修改内容

- `0 -> +5 cm` 任务分支未改动。
- `+5 -> -5 cm` 的全部 `TASK_NEGATIVE_*` 参数未改动。
- 电机速度、加速度、零点和行程限位未改动。
