# 0135 - KEY1 负向终点五秒内稳定

## 修改原因

KEY1 从 `+5 cm` 折返时，负向捕获制动过早在约 `-3.4 cm` 触发，钢球在 `-3.7 cm` 附近来回振荡，无法在五秒内稳定到 `-5 cm`。

## 修改内容

- 保持 `0 -> +5 cm` 段的现有参数不变。
- 将 `-5 cm` 捕获制动触发距离从 `1.5 cm` 缩短到 `1.0 cm`，使制动从约 `-4.0 cm` 开始。
- 将负向低速控制区扩展到目标前后 `1.5 cm`，并使用独立的 `30 pulse` 静摩擦补偿，避免回弹后重新累积大倾角。
- 将 KEY1 最大运行时间限制为 `5000 ms`。

## 验证

- Keil 全量编译：`0 Error(s), 0 Warning(s)`。
