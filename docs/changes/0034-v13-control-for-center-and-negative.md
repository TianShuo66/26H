# 对 0cm 与 -5cm 使用 V13 连续控制

- 代码提交：本文件所在提交
- 日期：2026-07-31

## 需求

- `0cm` 和 `-5cm` 使用 V13 运行时控制逻辑。
- `+5cm` 现有逻辑保持不变。

## 修改内容

- `0cm/-5cm` 保留 V13 的 alpha-beta 观测器、位置到 `VREF` 外环、速度到倾角内环，以及 15 至 150 脉冲的低速静摩擦自适应。
- 移除只作用于 `0cm/-5cm` 的终端 `CAPTURE` 固定制动、跨帧锁存和近端补偿强制重置；电机倾角连续由 V13 速度误差计算。
- `+5cm` 仍使用原来的终端捕获制动和正向推进速度自适应，不改变其参数。
- 机械零点、电机相对脉冲命令、速度/加速度和软件行程限制未修改。
