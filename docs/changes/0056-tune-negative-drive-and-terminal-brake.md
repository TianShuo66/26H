# 0056 - 调整负向推进与终端制动

日期：2026-08-01

## 实测结论

两份负向日志存在两个不同阶段的问题：

- 一份在 `X=-3.3 cm` 时 `CAPTURE=0`，倾角已接近零，钢球停住，说明低速推进不足。
- 另一份在 `X=-3.9 cm` 时 `CAPTURE=1`、`TILT_REF=-70`，钢球在 `X=-4.4 cm` 提前折返，说明末端 `-70 pulse` 制动过强。

## 修改内容

仅调整 `TASK_NEGATIVE_*`：

- 低速推进判定：`1.5 cm/s` 提高到 `3.0 cm/s`。
- 起步倾角：`15` 提高到 `35 pulse`。
- 倾角递增：每 `250 ms` 增加 `5 pulse` 改为每 `80 ms` 增加 `10 pulse`。
- 自适应倾角上限：`150` 降为 `100 pulse`。
- 终端制动基础值：`35` 降为 `20 pulse`。
- 终端制动增益：`2` 降为 `1`。
- 终端制动上限：`70` 降为 `45 pulse`。

## 未修改内容

- `0 -> +5 cm` 控制分支未改动。
- 电机速度、加速度、零点和软件限位未改动。
- 负向近端制动开始位置保持距目标 `1.0 cm`。
- `-5 cm +/-0.7 cm` 连续 `800 ms` 后保持的规则未改动。
