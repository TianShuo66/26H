# 0071 - 按新原始点重新校正视觉 X

日期：2026-08-01

## 新标定数据

| 物理位置 | 原始视觉 X |
| --- | --- |
| `-5.0 cm` | `-5.9 cm` |
| `0.0 cm` | `-0.5 cm` |
| `+5.0 cm` | `4.4 cm` |

两侧量程分别为 `5.4 cm`、`4.9 cm`，不能由一条直线同时精确通过三点。

## 修改

- 优先让物理中心 O 精确对应 `X=0.0 cm`。
- 取两侧平均比例 `1.03`，使用：

```text
校正X = (原始X + 0.5) / 1.03
```

- 原始 `-0.5 cm` 校正为 `0.0 cm`。
- 原始 `4.4 cm`、`-5.9 cm` 分别校正为约 `+4.8 cm`、`-5.2 cm`，残余各约 `0.2 cm`。

## 未修改

- ZDT `-14.8°` 的机械水平零点不变。
- 控制器反馈增益、速度、加速度和按键功能不变。
