# 0108 - 提前 KEY1 负向捕获反制动

## 问题

- 以 `-5.0 cm` 为目标时，日志显示钢球在约 `-3.9 cm`、速度约 `-11.6 cm/s` 才进入反制动。
- 制动实际到位前钢球已冲到 `-5.8 cm`，随后反弹离开允许区间，最终在 `5000 ms` 超时。

## 修改

- KEY1 负向捕获反制动的启动误差从 `-1.5 cm` 提前到 `-2.0 cm`。
- 反制动强度、速度和加速度参数保持不变。
- `0 -> +5 cm` 及正向阶段不变。

## 预期

- 给电机额外约 `0.5 cm` 的行程建立反向倾角，在 `-4.3 ~ -6.0 cm` 内降低速度并完成稳定保持。
