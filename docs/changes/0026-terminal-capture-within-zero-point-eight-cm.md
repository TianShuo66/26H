# 终端捕获限制在 +/-0.8cm

- 代码提交：本文件所在提交
- 日期：2026-07-31

## 要求

- 回到目标后允许在 `+/-0.8 cm` 内小幅摆动，但不得带着速度冲出该范围。

## 修改内容

- 将终端状态范围由 `+/-1.5 cm` 收紧为 `+/-0.8 cm`。
- 误差在 2cm 内且钢球仍朝目标方向高速运动时，按实际速度追加反向终端制动；制动倾角范围为 35 至 70 脉冲。
- 进入 `+/-0.8 cm` 后禁止自适应静摩擦倾角继续累加，避免大补偿把钢球再次推出终端范围。
- 串口 `CONTROL` 行新增 `CAPTURE`：值为 1 表示终端制动正在生效。

## 涉及文件

- `Core/Src/main.c`
- `Core/Src/usart.c`
- `Core/Inc/usart.h`
