# 提前预测制动

- 代码提交：本文件所在提交（提交说明：`Trigger predictive braking earlier`）
- 日期：2026-07-31

## 问题

实测任务日志表明，首版模型计算的 `STOP_DIST` 偏小，钢球高速接近目标时反向倾角切入偏晚。此前提高倾角范围主要解决起动静摩擦，不能代替提前制动。

## 修改内容

- 正向球速度的模型制动加速度由 `48` 调低至 `24`，单位为 `0.1 cm/s^2`。
- 负向球速度的模型制动加速度由 `22` 调低至 `12`，单位为 `0.1 cm/s^2`。
- 速度阻尼增益由 `20` 提高至 `45`。

模型中的制动加速度是保守估计：数值降低后，`STOP_DIST = v^2 / (2a)` 增大，因此会更早产生反向倾角；速度阻尼同时增强，减少制动开始后的惯性滑行。
