# 分离 +5cm 与 0/-5cm 的自适应补偿

- 代码提交：本文件所在提交
- 日期：2026-07-31

## 需求

- `+5cm` 的既有起步与补偿逻辑不修改。
- 仅让回中心 `0cm` 和 `-5cm` 使用撤销 `0025` 后的低速补偿逻辑。

## 修改内容

- 目标为 `+5cm` 时保留推进速度低于 `VREF` 的 60% 才补偿、35 脉冲起步、120ms 更新和 10 脉冲快速释放。
- 目标为 `0cm` 或 `-5cm` 时使用绝对速度不高于 `1.5cm/s` 的判定、15 脉冲起步、250ms 更新和 5 脉冲释放。
- 任务从 `+5cm` 切换至 `-5cm` 时，重置补偿为 15 脉冲，避免正向累积补偿进入反向控制。
- 未修改位置/速度级联控制、电机参数、机械零点、行程限制或终端捕获制动。
