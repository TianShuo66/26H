# 验证平衡后保持倾角并衔接 KEY1

- 代码提交：本文件所在提交
- 日期：2026-07-31

## 需求

- 到达目标并确认平衡后，保持当前电机倾角，不再持续抖动修正。
- 回中心任务完成后，可直接从保持的倾角进入 KEY1 的 `O -> +5cm -> -5cm` 任务。

## 修改内容

- 新增回中心任务状态与保持状态。
- 位置误差不超过 `0.8cm`、速度不超过 `2.0cm/s` 并连续维持 `300ms` 后进入保持状态。
- 保持状态保留电机使能和当前倾角，但跳过后续控制周期的电机位置指令；串口输出 `TASK,HOLD`。
- KEY2 启动或重新启动回中心任务；中心保持状态下按 KEY1，直接进入正向任务，不禁用电机、不回机械零点、不重置当前电机倾角。
- `-5cm` 终点通过同一验证条件后也进入保持状态。
