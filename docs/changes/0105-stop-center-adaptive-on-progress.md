# 0105 - 中心点已有进展时停止静摩擦累加

## 问题

- 回中心日志显示钢球从约 `-2.8 cm` 向中心运动后，`ADAPT` 仍持续由 `55` 增长至 `125 pulse`。
- 该累加把速度推高到约 `9 cm/s`；钢球进入中心 `+/-2 cm` 时，现有反制动强度和电机跟随步长不足，无法及时减速。

## 修改

- `TASK_TO_CENTER` 复用“向目标有效进展”判定：实际速度达到期望速度的 `35%` 后，停止增加静摩擦补偿，并交回位置-速度闭环。
- 中心点动态反制动调整为 `30` 到 `60 pulse`。
- 中心点反制动时，电机单次快速跟随步长提高到 `40 pulse`，使反向倾角能及时到位。
- `TASK_TO_POSITIVE` 与 `TASK_TO_NEGATIVE` 的控制条件和参数未修改。

## 验证
