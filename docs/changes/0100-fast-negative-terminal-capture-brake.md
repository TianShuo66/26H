# 0100 - 加快负向末段反制动

## 问题

- 负向日志显示钢球在 `X=-4.0 ~ -4.2 cm` 已被常规速度环减速并折返，未到达要求的 `-4.5 ~ -6 cm` 范围。
- 反向制动的电机目标变化幅度较小，摆杆翻转不足够快。

## 修改

- 负向卡滞区推进范围由 `-2 ~ -4 cm` 扩展为 `-2 ~ -4.5 cm`。
- 在 `X=-4.5 cm` 后，若钢球仍以超过 `1.5 cm/s` 的速度向负方向运行，使用 `45 ~ 90 pulse` 的速度相关反制动覆盖普通倾角。
- 该反制动的单次步进上限为 `40 pulse`，并复用现有 `2200 RPM` 高速反向命令，缩短摆杆翻转时间。
- 反制动仅作用于 KEY1 负向阶段；`0 -> +5 cm`、中心点和普通电机参数不变。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过。
