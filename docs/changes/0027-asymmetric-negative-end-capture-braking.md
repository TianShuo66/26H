# -5cm 端保持式终端制动

- 代码提交：本文件所在提交
- 日期：2026-07-31

## 日志结论

- `+5cm` 端已满足当前行为要求，保持原有 2cm 提前制动区与 70 脉冲制动上限。
- 在 `-5cm` 段，日志显示 `CAPTURE` 虽已在接近目标时触发，但钢球一越过目标就退出制动，仍以约 `9.5 cm/s` 向反方向运动，导致大幅越界。

## 修改内容

- 终端制动触发后改为保持式：仅当速度降至 `1.0 cm/s` 以下才释放，跨过目标时不再立即撤销制动。
- 仅针对 `-5cm` 端，将制动开始距离提前至 3.5cm。
- 仅针对 `-5cm` 端，将制动基础倾角设为 55 脉冲、最大倾角设为 120 脉冲。
- `+5cm` 端的终端制动参数保持不变。
