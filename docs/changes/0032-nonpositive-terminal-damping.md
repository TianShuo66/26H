# 0cm 与 -5cm 末端减摆

- 代码提交：本文件所在提交
- 日期：2026-07-31

## 日志结论

- `REF=-5.0` 时，钢球在距目标约 `3.2cm`、速度 `2.2cm/s` 就触发捕获制动，并很快达到 `-70` 脉冲。
- 制动将钢球停在约 `-3cm`，随后静摩擦补偿升至 20 脉冲，把钢球再次推离目标，形成持续摆动。

## 修改内容

- `+5cm` 的终端捕获参数保持不变。
- 回中心 `0cm` 的捕获制动调整为 2.5cm 区内、25 至 50 脉冲；不跨目标锁存。
- `-5cm` 的捕获制动调整为 1.5cm 区内、25 至 50 脉冲；锁存超过该区域即释放，防止在目标外侧持续反推。
- 对 `0cm/-5cm`，进入距目标 2.5cm 后将静摩擦补偿固定为最小 15 脉冲，不再累积到 20 脉冲以上。
