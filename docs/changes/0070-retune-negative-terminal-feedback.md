# 0070 - 重新调整负五厘米终端反馈

日期：2026-08-01

## 日志结论

在已校正机械和视觉基准后的完整任务中：

- `0 -> +5 cm` 在约 `1.9 s` 到达 `X=4.8 cm`，推进段正常。
- 进入 `-5 cm` 时，钢球在 `X=-2.9 cm`、距目标约 `2.0 cm` 即触发 `CAPTURE=1`。
- 制动输出达到 `-70 pulse`，钢球仅到 `X=-3.8 cm` 就反向，最终 `TASK,TIMEOUT`。

## 修改

仅调整 `-5 cm` 终端制动反馈：

- 制动区由 `2.0 cm` 缩小为 `1.0 cm`。
- 基础制动由 `35 pulse` 降为 `20 pulse`。
- 速度增益由 `2` 降为 `1`。
- 最大制动由 `70 pulse` 降为 `45 pulse`。

这样钢球会先进入更接近 `-5 cm` 的区域，再以受限制动减速，避免提前在 `-3.8 cm` 反向。
