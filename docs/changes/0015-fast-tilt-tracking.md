# 快速摆杆跟随与保守起步倾角

- 代码提交：本文件所在提交（提交说明：`Track large tilt changes at high speed`）
- 日期：2026-07-31

## 输入日志结论

最新日志为纯反馈版本，字段为 `ERR/VEL`，没有预测停车距离。目标附近的大回摆来自低速静摩擦补偿直接给出 `TILT_REF=+/-100`，而摆杆实际转向后的后续帧又回到普通速度；实际倾角无法及时追上制动目标。

## 修改内容

- 静摩擦起步倾角从 `100` 脉冲降至 `60` 脉冲，降低钢球获得的初始动能。
- 当摆杆目标和实际位置相差至少 `24` 脉冲时，整个追踪过程持续使用 `2200 RPM`、加速度 `400`、单次最大 `24` 脉冲，而不是只有第一次反向命令高速。
- 实际命令反向仍会立即停旧命令并使用同一套高速参数。
- 串口新增 `FAST,0/1`；`FAST,1` 表示摆杆正以高速追踪较大的倾角变化。
