# 0082 - 恢复 -5 cm 实时闭环反馈

## 原因

固定 `+35/-70 pulse` 序列依赖折返时的初始速度。实测中该速度会随正向末端状态变化，固定时间或固定位置切换均无法同时避免早停和越界。

## 修改

- 删除 `+5 -> -5 cm` 的固定推进、固定制动和定时切换状态。
- 恢复负向实时级联控制：视觉位置生成期望速度，视觉速度与期望速度的差生成实时倾角。
- 保留负向终端制动参数与最终稳定确认：`-5 cm +/-0.7 cm`、`|速度| <= 2 cm/s`、持续 800 ms 后冻结倾角。

## 未修改

- `0 -> +5 cm` 的代码和参数。
- 机械水平零点 `-14.8` 度。
- 用户本地设置的 700 ms 反向助推和 10 s 任务超时。
