# 0110 - 0 cm 与 -5 cm 共用末段反制动

## 原因

- 完全移除负向专属制动后，钢球接近 `-5 cm` 时仍带有约 `4.5 cm/s` 的负向速度。
- 中心点的常规末段微调不足以消除这部分动能，钢球反弹至约 `-3.7 cm`，KEY1 在 `5000 ms` 超时。

## 修改

- 已有的通用 `ApplyTerminalCaptureBrake()` 现在同时用于 `TASK_TO_CENTER`、`TASK_TO_NEGATIVE` 与 `+5 cm`。
- `0 cm`、`-5 cm`、`+5 cm` 共用同一套根据位置误差和速度计算的末段反制动，不恢复负向专属曲线补偿或捕获参数。
- -5 cm 的位置-速度级联、末段微调、静摩擦和 800 ms 稳定判定保持不变。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过，`0 Error(s), 0 Warning(s)`。
