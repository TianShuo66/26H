# 延后静摩擦补偿

- 代码提交：本文件所在提交（提交说明：`Delay static compensation until settled`）
- 日期：2026-07-31

## 输入日志结论

在 `REF=+5.0 cm` 的日志中，钢球仍以 `0.7 cm/s` 运动时，控制已经从普通反馈倾角 `-22` 跳到静摩擦补偿 `-60`；之后静态偏置继续将目标增加至约 `-110` 脉冲。这会在钢球尚未停稳时过早施加补偿。

## 修改内容

- 运动阈值由 `1.0 cm/s` 收紧至 `0.3 cm/s`。
- 速度进入阈值后还须连续静止 `160 ms`，才允许静摩擦补偿和静态偏置。
- 静态偏置步长由 `10` 降至 `5` 脉冲，上限由 `60` 降至 `30` 脉冲。
- 串口新增 `STATIC,0/1`，用于区分普通位置速度反馈和静摩擦补偿。
