# 0073 - 更新机械水平至负 10.3 度

日期：2026-08-01

## 标定依据

ZDT 电机驱动器显示 `-10.3°` 时，机构机械水平：

```text
-10.3 / 360 * 65536 = -1875.1 counts
```

取最近整数 `-1875 counts`。

## 修改

- 将 `MOTOR_FIXED_ZERO_COUNTS` 从 `-1365` 更新为 `-1875`。
- ZDT 显示约 `-10.3°` 时，软件相对倾角 `PULSE=0`、`TILT_REF=0`。

## 未修改

- 视觉 X 校正、速度、加速度、闭环参数和按键逻辑未修改。
