# 0120 - 增加 UART5 与 OLED 运行时间显示

## 硬件配置

- UART5：`PC12=TX`、`PD2=RX`，`115200 8N1`，启用接收中断。
- OLED：I2C2，`PB10=SCL`、`PB11=SDA`，400 kHz。
- OLED 驱动按 0.96 寸常见的 `SSD1306`、I2C 地址 `0x3C`、`128x64` 配置。

## 行为

- 屏幕显示 MCU 上电后的运行时间，格式为 `HH:MM:SS`，每秒刷新。
- OLED 未连接或初始化失败时，显示功能自动关闭，不影响电机闭环控制。
- UART5 接收采用单字节中断；业务帧解析等待串口通信协议确认后接入。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过，`0 Error(s), 0 Warning(s)`。
