# 回中心高速穿越阻尼

- 代码提交：本文件所在提交

## 日志结论

- 回中心过程中，钢珠穿过 `0 cm` 时速度仍在约 `11 cm/s`，原逻辑已进入 `+/-18 pulse` 微调上限，制动不足。
- 钢珠离开 `+/-1.5 cm` 后，倾角又立刻恢复为 `50~120 pulse`，造成越来越大的两侧摆动。

## 修改内容

- `0 cm` 回中心只有在速度不超过 `3 cm/s` 时才进入原 `+/-18 pulse` 精细微调。
- 高速穿越中心时仍使用位置速度闭环制动，但回中心倾角限制为 `+/-45 pulse`，防止出现日志中的 `+121/-99 pulse` 大倾角。
- 卡滞脱困逻辑仍可超过该限制，最高保持 `80 pulse`，只在视觉位置无进展时使用。
- `+5 cm` 与 `-5 cm` 控制路径未修改。
