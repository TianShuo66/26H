# 0079 - +5 cm 折返后使用固定负向序列

## 目的

`0 -> +5 cm` 保留已有闭环控制。钢球折返后不再使用连续变化的负向倾角，而是使用由视觉位置切换的固定倾角序列。

## 固定序列

| 阶段 | 切换条件 | 固定倾角 |
| --- | --- | ---: |
| 负向推进 | 收到 `TASK,REVERSE` 后 | `+35 pulse` |
| 负向制动 | `X <= -3.5 cm` | `-70 pulse` |
| 最终保持 | `-5 cm +/-0.7 cm` 且 `|速度| <= 2 cm/s` 连续 800 ms | 冻结当前实际倾角 |

脉冲值和制动切换点来自已保存的固定序列测试（`0052`、`0053`），只复用其中 `+5 -> -5` 段。

## 未修改

- `0 -> +5 cm` 的代码和参数。
- 回中心控制。
- 电机速度、加速度、机械水平零点和视觉坐标标定。
