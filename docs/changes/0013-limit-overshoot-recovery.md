# 收紧反制动范围并补偿终点静摩擦

- 代码提交：本文件所在提交（提交说明：`Limit overshoot recovery near target`）
- 日期：2026-07-31

## 输入日志结论

在 `REF=-5.0 cm` 的最新日志中，快速回收从 `-5.3 cm` 持续到 `-7.2 cm`，又将钢球回摆至约 `-2.8 cm`。原因是 `RECOVERY,1` 在目标两侧 `2.5 cm` 内持续强制 `+/-100` 脉冲，形成新的大幅摆动。最终停在约 `-6.2 cm`，距目标 `1.2 cm`，而原有 `1.5 cm` 静摩擦阈值没有启动补偿。

## 修改内容

- 快速回收仅在距离目标 `1 cm` 内启用，最小反向倾角由 `100` 脉冲降至 `60` 脉冲；仍保持 `1800 RPM` 与 `24` 脉冲的快速步进。
- 将负向速度的模型制动减速度从 `1.8 cm/s^2` 修正为 `3.0 cm/s^2`，减少该方向因停车距离被高估而产生的过早制动。
- 静摩擦补偿触发阈值从 `1.5 cm` 降至 `1 cm`，位置误差超过任务允许值时会继续主动修正。
