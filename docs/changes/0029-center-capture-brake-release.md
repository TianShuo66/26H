# 回中心终端制动释放

- 代码提交：本文件所在提交
- 日期：2026-07-31

## 日志结论

- 回中心 `REF=0.0` 的日志中，钢球经过中心后，`CAPTURE=1` 仍持续输出 `TILT_REF=+/-70`。
- 捕获制动锁存没有检查目标是否已被穿过，使钢球在中心两侧约 `-7.3cm` 到 `+4.4cm` 间反复摆动。

## 修改内容

- 将跨控制周期的终端制动锁存限定为 `TASK_TO_NEGATIVE`，即 `+5cm` 折返到 `-5cm` 的任务末端。
- `REF=0.0` 回中心和其他普通闭环仍可在 2cm 制动区内即时反制动；球穿过目标后会在下一控制周期释放锁存，交回级联位置/速度控制。
- 未修改机械零点、软件行程、电机相对脉冲接口或电机速度参数。
