# 0089 - -5 cm 中段曲率补偿

## 原因

从中心运行到 `-5 cm` 时，机械轨道在约 `-2 ~ -3 cm` 存在曲率，钢球在低速时会停在该位置。通用中心点闭环仍保持不变，但需要一个小的定向补偿以越过该机械阻力区。

## 修改

- 保留 `-5 cm` 对中心点闭环参数、末段微调和速度反馈制动的复用。
- 当目标为 `-5 cm`、位置误差处于 `-3.5 ~ -1.5 cm`、且钢球未以超过 `1.5 cm/s` 的速度向目标运动时，叠加 `+12 pulse` 朝负向的曲率补偿。
- 进入最后 `1.5 cm` 微调区或已经快速向目标推进时，不施加该补偿。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过。
