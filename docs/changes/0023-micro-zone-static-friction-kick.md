# 微调区静摩擦起步脉冲

- 代码提交：本文件所在提交
- 日期：2026-07-31

## 问题

- 微调区收紧到目标 `+/-1.5 cm` 后，连续倾角被限制为 `+/-24` 脉冲。
- 位置环在该误差范围内输出约 `15` 脉冲，且原逻辑禁止微调区静摩擦补偿；钢球可能停在微调区内而无法进入 `+/-0.5 cm` 任务完成范围。

## 修改内容

- 微调区保留原有 `+/-24` 脉冲连续小倾角控制。
- 误差大于 `+/-0.5 cm`、钢球低速保持 160ms 后，给出一次朝目标方向的 `60` 脉冲起步倾角，持续 160ms。
- 每次起步后冷却 360ms；小球跨过目标方向时立即撤销起步脉冲。视觉检测到运动后会重置静止判定，禁止下一次补偿。
- 串口原有 `STATIC,1` 可指示起步脉冲正在生效，`TILT_REF` 将短时显示 `+/-60`。
