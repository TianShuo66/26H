# 0103 - 收敛中心点静摩擦脱困与反制动

## 问题

- 中心点在 `+/-1.2 cm` 左右速度变小后，静摩擦补偿从 `25 pulse` 每 `80 ms` 增加 `10 pulse`，很快升至 `70 pulse`。
- 钢球开始向中心运动时，补偿仍持续施加，导致越过中心后在两侧反复摆动。

## 修改

- 仅 `TASK_TO_CENTER` 的末段静摩擦脱困改为每 `120 ms` 增加 `5 pulse`，范围为 `25` 到 `50 pulse`。
- 脱困仅在估计速度不超过 `0.6 cm/s` 时触发；已经运动的钢球交回位置-速度闭环。
- 中心点独立启用末段反制动：钢球在 `+/-2 cm` 内、朝中心速度超过 `1.2 cm/s` 时，输出 `24` 到 `45 pulse` 的反向制动。
- 未修改 `TASK_TO_POSITIVE` 或 `TASK_TO_NEGATIVE`，KEY1 的 `0 -> +5 -> -6` 逻辑保持不变。
