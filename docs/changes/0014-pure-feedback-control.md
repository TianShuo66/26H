# 纯位置速度闭环控制

- 代码提交：本文件所在提交（提交说明：`Use pure position velocity feedback`）
- 日期：2026-07-31

## 输入日志结论

停车距离预测、固定提前制动与固定越界回收先后叠加后，钢球在 `REF=-5.0 cm` 附近仍出现大幅往复摆动，模型参数难以通过少量测试收敛。

## 修改内容

- 删除预测停车距离、提前制动和固定反制动倾角。
- 控制目标只由实时位置误差和实时速度计算：位置误差推动钢球靠近目标，速度项提供阻尼并在速度过大时自动反向。
- 保留实际命令方向发生变化时的 `1800 RPM`、最大 `24` 脉冲快速反向；不再因预测提前反向。
- 串口控制行改为 `ERR`（位置误差，单位 cm）和 `VEL`（滤波速度，单位 0.1 cm/s），不再输出预测停车字段。
