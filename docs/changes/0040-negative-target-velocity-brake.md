# -5cm 目标速度反馈制动

- 代码提交：本文件所在提交
- 日期：2026-07-31

## 日志结论

- 钢珠从 `X=-7.5 cm` 向 `-5 cm` 接近时，速度由 `1.4 cm/s` 上升至约 `5.8 cm/s`。
- 原 `-5 cm` 路径没有终端速度制动，钢珠越过 `-5 cm` 后漂移至 `-3.4 cm`。
- 在该位置，通用静摩擦补偿只在 `20~30 pulse` 间切换，无法消除这次过冲造成的大误差。

## 修改内容

- 为 `TASK_TO_NEGATIVE` 增加与已验证的 `+5 cm` 相同的速度反馈制动。
- 仅在距 `-5 cm` 不超过 `2 cm`、速度超过 `1.5 cm/s` 且仍朝目标运动时制动。
- 制动力依据实时速度在 `35~70 pulse` 间变化，方向始终与钢珠运行方向相反。
- 其他时刻仍使用原 V13 位置速度闭环；`+5 cm` 路径未改动。
