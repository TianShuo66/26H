# 0cm 与 -5cm 卡滞位置进展补偿

- 代码提交：本文件所在提交
- 日期：2026-07-31

## 问题

视觉坐标长期停在同一位置时，alpha-beta 观测器的速度估计仍可能正负变化。原静摩擦补偿会据此撤销倾角，导致钢珠在离目标较远的位置卡住。

## 修改内容

- 仅在回 `0 cm` 与前往 `-5 cm` 时，使用每帧有效视觉坐标检查到目标的实际距离是否缩小。
- 在连续 `320 ms` 内未向目标缩小至少 `0.1 cm` 且误差仍超过 `0.7 cm` 时，开启卡滞补偿。
- 卡滞补偿从 `25 pulse` 开始，每 `320 ms` 增加 `10 pulse`，最大 `80 pulse`；倾角方向始终指向当前目标。
- 观察到位置推进或钢珠进入 `+/-0.7 cm` 后立即撤销补偿并回到原位置速度闭环。
- 直接启动 `-5 cm` 的按键也会进入 `TASK_TO_NEGATIVE`，因此同样使用脱困与稳定保持逻辑。
- `+5 cm` 的控制路径没有改动。
