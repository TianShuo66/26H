# 0102 - 回中心末段静摩擦脱困

## 问题

- 中心点最后 `1.5 cm` 微调分支每个控制周期都将补偿重置为 `25 pulse`。
- 当该倾角无法克服静摩擦时，钢球保持静止，补偿不会继续增大。

## 修改

- 仅对 `TASK_TO_CENTER`，在存在位置误差且速度接近零时，末段补偿每 `80 ms` 从 `25 pulse` 增加 `10 pulse`，最高为 `70 pulse`。
- 一旦钢球开始运动或进入 `0.5 cm` 中心死区，补偿每 `80 ms` 逐步降回 `25 pulse`，由位置-速度反馈接管。
- `TASK_TO_NEGATIVE` 保持原有 `18 pulse` 固定末段策略，KEY1 的 `0 -> +5 -> -6` 不受此脱困逻辑影响。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过。
