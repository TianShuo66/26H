# 0141 - 增强 KEY1 负向末段低速驱动力

## 修改原因

实测中钢球在负向目标右侧约 `1.5 ~ 2.0 cm` 处低速回弹。静摩擦补偿仅为 `30 pulse`，不足以快速重新建立负向运动，任务在 `5000 ms` 时仍停在约 `-4.2 cm`。

## 修改内容

- 将负向目标末段静摩擦推进从 `30 pulse` 增至 `50 pulse`。
- 将负向目标低速自适应倾角初值同步从 `30 pulse` 增至 `50 pulse`。
- 仅影响 `5 -> 负向目标` 的最后 `1.5 cm` 低速卡滞恢复；`0 -> +5 cm`、负向终点的 `0.5 cm` 捕获制动、目标坐标与机械零点均不变。

## 验证

- Keil 全量编译：`0 Error(s), 0 Warning(s)`。
