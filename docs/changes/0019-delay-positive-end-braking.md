# 延后 +5cm 端点速度制动

- 代码提交：本文件所在提交（提交说明：`Delay positive endpoint braking zone`）
- 日期：2026-07-31

## 修改内容

- 朝 `+5 cm` 靠近时，距离目标大于 `1 cm` 不再使用速度制动项，只按位置误差推进。
- 剩余距离进入 `1 cm` 后，启用速度反馈增益 `30` 进行制动。
- 原有 `+/-2 cm` 微调区和 `+/-24` 脉冲倾角上限保持不变。

这样正向制动不会在远离 `+5 cm` 的位置提前发生。
