# +5cm 端点限速进入微调区

- 代码提交：本文件所在提交（提交说明：`Limit positive approach speed before micro zone`）
- 日期：2026-07-31

## 输入日志结论

把正向速度制动延后至最后 `1 cm` 后，钢球在 `ERR=0.8 cm` 时速度仍约为 `13.7 cm/s`。虽然已经进入 `MICRO,1`，但 `+/-24` 脉冲微调无法在 `2 cm` 内减掉该速度，钢球越过至约 `+8.7 cm`。

## 修改内容

- 正向速度反馈在距 `+5 cm` 剩余 `3 cm` 时才开始，而非远距离全程介入。
- 正向推进阶段的摆杆目标限制为 `+/-60` 脉冲，限制进入微调区前的动能。
- 进入 `+/-2 cm` 后仍使用原有 `+/-24` 脉冲微调，不使用大倾角。
