# 降低 0cm 捕获制动力

- 代码提交：本文件所在提交
- 日期：2026-07-31

## 日志结论

- 回中心时，`CAPTURE=1` 在速度约 `2.1~2.9cm/s` 已输出 `37~50` 脉冲的反制动倾角。
- 该制动力对中心点附近的摆动偏强。

## 修改内容

- 仅将 `0cm` 终端捕获制动范围从 `25~50` 脉冲下调为 `15~30` 脉冲。
- 未修改 `+5cm`、`-5cm` 的捕获制动参数、触发距离、静摩擦补偿或电机参数。
