# 0080 - 机械水平零点改为 -14.8 度

## 变更

- 将 `MOTOR_FIXED_ZERO_COUNTS` 从 `-1365` 改为 `-2695`。
- 软件的 `PULSE=0` 和 `TILT_REF=0` 对应 ZDT 驱动器显示 `-14.8` 度时的机械水平位置。

## 换算

电机一圈位置反馈为 65536 counts：

```text
-14.8 / 360 x 65536 = -2694.94 counts
```

取整后使用 `-2695` counts。
