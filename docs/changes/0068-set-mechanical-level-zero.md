# 0068 - 设置机械水平零点

日期：2026-08-01

## 标定依据

ZDT 电机驱动器显示角度 `-14.8°` 时，机构机械水平。根据驱动器位置反馈换算：

```text
-14.8 / 360 * 65536 ≈ -2695 counts
```

结合实际反馈取 `-2696 counts`。

## 修改

- 将 `MOTOR_FIXED_ZERO_COUNTS` 从 `0` 改为 `-2696`。
- 软件的 `PULSE=0`、`TILT_REF=0` 现在对应驱动器显示约 `-14.8°` 的机械水平位置。

## 未修改

- 视觉 X 坐标的比例和零点校正保持不变。
- 电机速度、加速度、闭环增益和按键逻辑未修改。
