# 0083 - -5 cm 速度相关反制动

## 原因

负向折返原来的末端制动固定在距离目标 `1.6 cm` 内才允许触发，且速度超过 `5 cm/s` 时的反向倾角较小。高速到达 `-5 cm` 时制动开始过晚，无法在任务时间内一次停住。

## 修改

- 仅调整 `+5 -> -5 cm` 的实时闭环末端制动；`0 -> +5 cm` 代码和参数没有改动。
- 负向制动区仍以 `1.6 cm` 为基准，但随实测速度按 `速度 / 10` 扩展，最大为 `3.5 cm`。速度越快越早开始反制动。
- 将负向制动触发速度由 `5 cm/s` 降至 `3 cm/s`，并将反制动起始倾角由 `12 pulse` 提升至 `20 pulse`，最大值由 `45 pulse` 提升至 `70 pulse`。
- 制动方向持续与钢球当前速度相反；速度降至阈值内或发生反向后，自动交还普通级联闭环，避免固定制动导致二次回落。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过。
