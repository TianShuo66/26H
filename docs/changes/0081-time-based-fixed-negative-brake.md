# 0081 - 固定负向制动改为定时切换

## 日志结论

固定推进 `+35 pulse` 后，以 `X=-3.5 cm` 为制动切点时，钢球速度仍约 `-11.4 cm/s`。切换 `-70 pulse` 后仍冲到 `-8.5 cm`，位置阈值已不足以提供制动距离。

同一日志显示，从 `TASK,REVERSE` 起约 1500 ms 时钢球位于中心附近，之后到 `-5 cm` 尚有足够距离制动。

## 固定序列

| 阶段 | 触发条件 | 固定倾角 |
| --- | --- | ---: |
| 负向推进 | `TASK,REVERSE` 后的前 1500 ms | `+35 pulse` |
| 负向制动 | 折返满 1500 ms | `-70 pulse` |
| 最终保持 | `-5 cm +/-0.7 cm` 且 `|速度| <= 2 cm/s` 连续 800 ms | 冻结当前实际倾角 |

## 未修改

- 电机速度、加速度、机械水平零点和视觉坐标标定。
