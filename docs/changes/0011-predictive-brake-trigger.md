# 预测制动触发与快速摆杆

- 代码提交：本文件所在提交（提交说明：`Trigger predictive braking before overshoot`）
- 日期：2026-07-31

## 输入日志结论

最新固件的日志已确认远离目标时不再提前制动；但在 `REF=+5.0 cm` 时，钢球进入离目标 `2 cm` 的终端区后才开始制动。此时摆杆仍处于大角度，目标又被限制为 `+/-80` 脉冲，钢球越过 `+5 cm` 到约 `+6.5 cm`，随后出现大幅回摆。

## 修改内容

- 每个控制周期估计当前速度下的停车距离。
- 仅当钢球正在朝目标运动，且“停车距离 + 摆杆反向延迟距离 + 0.4 cm 安全距离”达到剩余距离时，启用预测制动。
- 预测制动启用后不再受终端区 `+/-80` 脉冲限制，可使用原有 `+/-160` 脉冲；摆杆以 `1800 RPM`、单次最大 `24` 脉冲快速反向。
- 串口控制行新增 `BRAKE,0/1`，`1` 表示预测制动当前已接管控制。

这样钢球远离目标时仍能加速，制动则根据当前速度和摆杆反向时间提前介入。
