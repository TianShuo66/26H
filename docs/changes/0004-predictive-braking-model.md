# 基于实测数据的预测制动模型

- 代码提交：`840ee9c`
- 日期：2026-07-31

## 输入数据

- `TARGET,+40` 时，钢球向负方向加速。
- `TARGET,-40` 时，钢球向正方向加速。
- 两个方向的实际制动力明显不同，因此不能使用同一个固定制动速度。

## 修改内容

- 新增非对称反向制动加速度：正向球速度使用 `48`，负向球速度使用 `22`，单位均为 `0.1 cm/s^2`。
- 使用 `STOP_DIST = v^2 / (2a)` 计算预测停车距离，最大限制为 `10 cm`。
- 使用 `PRED_ERR = x_ref - x_predicted_stop` 代替高速运动时的单纯位置误差，提前给出反向倾角。
- 仅当速度达到 `1.0 cm/s` 时使用预测制动；低速时保留原有静摩擦补偿。
- 串口 `CONTROL` 日志增加 `STOP_DIST` 和 `PRED_ERR` 字段。

## 后续调参依据

- 若球仍越过目标点，增大对应速度方向的制动加速度常量。
- 若球过早反向并停在目标前，减小对应速度方向的制动加速度常量。
