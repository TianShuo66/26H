# 0078 - 增加 -5 cm 高速制动力

## 日志结论

负向制动在 `X=-3.7 cm`、速度约 `-10.4 cm/s` 已触发，但 `30 pulse` 上限将实际制动命令限制为 `-30 pulse`。钢球仍以约 `-9.0 cm/s` 穿过 `-5 cm`，最终到达 `-6.1 cm`，未能进入稳定保持区。

## 修改

仅修改负向终端制动：

| 参数 | 原值 | 新值 |
| --- | ---: | ---: |
| 制动区 | 1.2 cm | 1.6 cm |
| 最大制动 | 30 pulse | 45 pulse |

高速接近时会更早使用足够的反向制动力来降低速度。触发速度、基础制动及所有 `+5 cm` 参数保持不变。

## 未修改

- `+5 cm` 的所有代码和参数。
- 最终稳定确认和冻结倾角逻辑。
- 电机速度、加速度、机械水平零点和视觉坐标标定。
