# 0149 - 调整 KEY3 的 +7cm 末段制动

## 修改原因

KEY3 的末段制动已触发，但从 `X=4.2 cm` 开始即输出约 `+39 pulse`，钢球在 `X=5.2 cm` 已被制停并回滚。随后静摩擦补偿在钢球仍有明显速度时重新增大，导致大范围循环。

## 修改内容

- KEY3 末段制动触发范围从距目标 `3.0 cm` 收窄为 `1.5 cm`。
- 制动开始速度从 `20 cm/s` 提高到 `30 cm/s`。
- 制动输出从 `30~60 pulse` 降为 `15~35 pulse`。
- 静摩擦补偿触发速度从 `25 cm/s` 降为 `12 cm/s`，只有接近停滞时才叠加大倾角。
- KEY1 和 KEY2 未修改。

## 验证

- Keil 全量编译：`0 Error(s), 0 Warning(s)`。
