# 0147 - 为 KEY3 的 +7cm 目标设置独立参数

## 修改原因

KEY3 复用中心点参数时，在到达 `+7 cm` 的途中会在约 `X=3~4.6 cm` 停滞。此时位置误差仍约 `2.4 cm`，但速度估计为 `17 cm/s`，中心参数仅计算出约 `-6 pulse`，不足以克服该段静摩擦。

## 修改内容

- KEY3 保持与中心点相同的级联闭环与静摩擦补偿算法结构。
- 新增 KEY3 独立参数组，不再共享中心点数值。
- 位置速度环增益从 `1.3` 提高到 `1.6`，倾角速度环增益从 `0.45` 提高到 `0.55`。
- 静摩擦补偿的初始倾角提高到 `35 pulse`，速度门限提高到 `25 cm/s`，补偿上限保持为安全的 `155 pulse`。
- KEY1 的 `0 -> +5 -> -6` 与 KEY2 的回中心参数未修改。

## 验证

- Keil 全量编译：`0 Error(s), 0 Warning(s)`。
