# 0065 - 按键校正视觉 X 零点

日期：2026-08-01

## 操作

1. 电机不运行时，将钢球放在机械中心 O。
2. 同时按下 `KEY3 + KEY4`。
3. 程序使用当前原始视觉 X 值作为新的零点偏置。

串口成功反馈格式：

```text
VISION,ZERO,RAW,-10.2,OFFSET,-10.2
```

校正后，当前钢球位置会显示为 `X=0.0`。没有有效视觉数据或闭环正在运行时，串口会输出拒绝原因。

```text
VISION,ZERO,REJECT,NO_VISION
VISION,ZERO,REJECT,ACTIVE
```

## 实现

- 保留 `-10.2 cm` 的上电默认视觉偏置。
- `KEY3 + KEY4` 校正只覆盖 RAM 中的偏置，复位后恢复默认值。
- 校正后重置视觉位置观测器，防止旧的坐标估计影响下一次任务。
- KEY3、KEY4 单独按下时原有的 `+5 cm`、`-5 cm` 功能不变。
