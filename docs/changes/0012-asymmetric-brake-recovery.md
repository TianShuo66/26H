# 区分制动与反制动

- 代码提交：本文件所在提交（提交说明：`Strengthen target overshoot recovery`）
- 日期：2026-07-31

## 输入日志结论

`BRAKE,1` 表明预测制动已经能快速翻转摆杆。但钢球越过目标并高速远离后，`BRAKE` 随即变为 `0`，控制器退回普通的 `12` 脉冲步长和小倾角追随，反向拉回不足。

## 修改内容

- 将预测制动的摆杆延迟补偿由 `320 ms` 调低至 `220 ms`，安全距离由 `0.4 cm` 调低至 `0.2 cm`，使接近目标时的制动更晚、更弱。
- 增加目标越界后的快速回收：钢球在目标 `2.5 cm` 内高速远离时，强制提供至少 `100` 脉冲的反向倾角。
- 快速回收同样使用 `1800 RPM` 与单次最大 `24` 脉冲，确保反制动比普通跟随更快。
- 串口新增 `RECOVERY,0/1`；`RECOVERY,1` 表示已进入越界快速回收。
