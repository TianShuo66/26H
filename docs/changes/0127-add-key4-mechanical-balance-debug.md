# 0127 - KEY4 机械平衡点调试模式

## 操作

- 普通状态按 KEY4：停止当前闭环任务并进入机械平衡调试模式。
- 调试模式中，KEY1 相对移动 `+5 pulse`，KEY2 相对移动 `-5 pulse`。
- KEY3 读取电机当前位置，并保存为当前上电周期的机械平衡零点。
- 调试模式中再次按 KEY4：停止并退出调试模式。

## 运行效果

- 保存后的机械零点立即用于后续 KEY1、KEY2、KEY3 闭环任务。
- 串口输出 `BALANCE,ENTER/STEP/SAVE/EXIT`，包含电机原始位置和相对零点脉冲。
- 机械零点不写入片内 Flash；重新上电后恢复编译时的默认值。
