# 0107 - KEY1 负向目标改为 -5 cm

## 目标

- KEY1 需要在 `5000 ms` 内稳定于负向区间 `-4.3 ~ -6.0 cm`。

## 修改

- 将 KEY1 的负向闭环目标从 `-6.0 cm` 改为允许区间中部的 `-5.0 cm`。
- 终点连续 `800 ms` 稳定保持逻辑不变；现有 `+/-0.7 cm` 保持窗口对应 `-5.7 ~ -4.3 cm`，完整落在允许区间内。
- `0 -> +5 cm` 推进、反转条件和正向终端制动不变。

## 原因

- 日志中钢球虽然可到达 `-5.9 cm`，但到达时速度过高，剩余时间不足以完成稳定保持。
- 将控制目标移至允许区间中部，使反制动提前约 `1 cm` 生效，给稳定保持留出时间。
