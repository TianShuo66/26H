# 0053 - 降低固定任务的正负向动量

日期：2026-08-01

## 实测问题

固定任务日志显示：

- `-65 pulse` 一直保持至 `X=+3.2 cm`，切换 `+70 pulse` 后钢球仍冲到 `+7.6 cm`。
- `+70 pulse` 同时作为左向推进时，钢球左向速度达到约 `18 cm/s`。
- 在 `X=-4.9 cm` 才开始 `-70 pulse` 制动，钢球已经冲到 `-11.2 cm`。

## 修改内容

1. `X=+1.0 cm` 后由 `-65 pulse` 改为 `0 pulse`，让钢球滑行，避免继续累积右向动量。
2. `X=+3.1 cm` 再施加 `+70 pulse` 右向制动。
3. 到达 `+4.8 cm` 后，左向固定推进由 `+70 pulse` 降为 `+35 pulse`。
4. 负向固定制动起点由 `-4.2 cm` 前移至 `-3.5 cm`，保持 `-70 pulse`。

## 未修改内容

- 相位仍只由视觉坐标切换，电机倾角仍是固定值。
- `-5 cm +/-0.7 cm` 连续 `800 ms` 后冻结倾角的规则未改动。
- Key2、Key3、Key4 和电机硬件参数未改动。
