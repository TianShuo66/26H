# 0084 - 加强 -5 cm 低速推进

## 问题

`+5 -> -5 cm` 折返后，钢球在约 `-2.3 cm` 附近仍距离目标 `2.7 cm`。串口显示低速段的 `TILT_REF` 仅为 `19~25 pulse`，视觉坐标不再继续向负方向推进，最终在 5 秒任务超时前无法到达 `-5 cm`。

## 修改

- 仅调整负向目标的自适应推进参数，`0 -> +5 cm` 未修改。
- 最小推进倾角由 `15` 提高至 `35 pulse`。
- 推进补偿步长由 `5` 提高至 `10 pulse`，更新周期由 `250 ms` 缩短为 `120 ms`。
- 低速推进保持门限由 `1.5 cm/s` 提高至 `3.0 cm/s`，避免视觉速度在约 `2 cm/s` 时过早撤销推动倾角。
- 保留实时速度相关的负向末端反制动；接近 `-5 cm` 且速度仍指向目标时，反制动仍会接管。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过。
