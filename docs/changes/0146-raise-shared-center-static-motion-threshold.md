# 0146 - 提高中心结构的低速静摩擦门限

## 修改原因

KEY3 的 `+7 cm` 测试中，钢球在 `X=4.6 cm` 停滞，速度估计保持在约 `17 cm/s`。原低速静摩擦门限为 `15 cm/s`，未触发补偿，控制仅输出约 `-6 pulse`，无法重新推动钢球。

## 修改内容

- 将中心控制结构的低速静摩擦触发速度从 `15 cm/s` 提高到 `20 cm/s`。
- 由于 KEY3 已复用中心控制结构，`0 cm` 与 `+7 cm` 同步采用该门限。
- KEY1 任务参数不变。

## 验证

- Keil 全量编译：`0 Error(s), 0 Warning(s)`。
