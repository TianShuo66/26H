# 0072 - 更新机械水平至负 7.5 度

日期：2026-08-01

## 新标定依据

ZDT 电机驱动器显示 `-7.5°` 时，机构机械水平。位置反馈一圈为 `65536 counts`：

```text
-7.5 / 360 * 65536 = -1365.3 counts
```

取最近整数 `-1365 counts`。

## 修改

- 将 `MOTOR_FIXED_ZERO_COUNTS` 从 `-2696` 更新为 `-1365`。
- ZDT 显示约 `-7.5°` 时，软件相对倾角 `PULSE=0`、`TILT_REF=0`。

## 未修改

- 视觉 X 三点校正不变。
- 电机速度、加速度、闭环增益和按键逻辑不变。
