# 0062 - 限制左侧回中心补偿

日期：2026-08-01

## 问题

回中心日志显示，钢球位于 `-2 cm` 附近时，`STATIC=1` 的自适应静摩擦补偿从 `15 pulse` 持续累加到 `40~60 pulse`。该输出不是终端制动（日志为 `CAPTURE=0`），但过大的倾角会妨碍钢球平稳通过该区间。

## 修改

- 对仅限回中心任务、且钢球从左侧 `-2~0 cm` 回归的区间，将自适应补偿上限限制为 `20 pulse`。
- 进入该区间时，立即将此前积累的补偿截断至该上限，避免保留区间外的大倾角。
- 正常的位置-速度级联控制仍持续运行；最后 `±0.7 cm` 仍使用原有小倾角微调。

## 未修改

- `+5 cm` 与 `-5 cm` 的控制参数和状态机逻辑未修改。
- 电机机械零点、速度、加速度和硬件接口未修改。
