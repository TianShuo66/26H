# 0077 - -5 cm 高速接近时提前减速

## 问题

`0076` 将负向制动区缩至 `0.8 cm` 后，制动到 `X=-4.4 cm` 才触发。此时钢球速度约为 `-11.4 cm/s`，即使限制为 `-30 pulse`，仍惯性越过至 `-6.4 cm` 并回弹，无法形成稳定保持。

此前从 `X=-3.9 cm` 以 `-45 pulse` 制动则过强，钢球在 `-4.5 cm` 已反向。问题是制动开始点过晚或制动力过大，而不是最终冻结逻辑。

## 修改

仅将 `-5 cm` 的终端制动区由 `0.8 cm` 扩展为 `1.2 cm`：

```text
制动区: 0.8 cm -> 1.2 cm
最大制动: 保持 30 pulse
触发速度: 保持 5.0 cm/s
```

高速钢球将从约 `-3.8 cm` 开始减速，制动幅值仍限制在 30 pulse，避免恢复 45 pulse 时的早停与回弹。

## 未修改

- `+5 cm` 的所有代码和参数。
- 最终稳定确认与冻结倾角逻辑。
- 电机速度、加速度、机械水平零点和视觉坐标标定。
