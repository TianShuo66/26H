# 回中心末段小倾角闭环微调

- 代码提交：本文件所在提交
- 日期：2026-07-31

## 日志结论

回中心任务从约 `-6 cm` 返回至 `-1.4 cm` 后，通用自适应补偿会在低速时逐步增加到 `25~35 pulse`，又在速度略有增加后撤销。电机倾角在大补偿与接近零之间切换，钢球持续在中心左侧摆动，无法进入最终稳定范围。

## 修改内容

- 仅在 `TASK_TO_CENTER` 的最后 `1.5 cm` 启用专用微调。
- 保持原有位置到速度、速度到倾角的级联闭环，但将末段倾角限制为 `+/-18 pulse`。
- 误差仍大于 `0.5 cm` 且球速不超过 `0.8 cm/s` 时，使用固定 `15 pulse` 起步补偿；补偿不再随时间累积。
- 速度恢复后立刻交还给速度环制动，避免原先 `25~35 pulse` 的反复切换。
- `+5 cm` 和 `-5 cm` 的控制路径、机械参数、电机速度与加速度均未改变。
