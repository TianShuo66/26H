# 仅以连续新视觉帧确认平衡后保持

- 代码提交：本文件所在提交
- 日期：2026-07-31

## 问题

原保持判定在 40 ms 主循环中运行。相机未提供新帧时，同一份位置和速度估计仍会被重复用于计时，因此少量满足阈值的数据可能被误判为已稳定。

## 修改内容

- `0 cm` 回中心和 `-5 cm` 终点仅在收到一帧新的、已被观测器接受的视觉数据时检查保持条件。
- 每一帧都必须满足位置误差不超过 `0.5 cm`、速度不超过 `0.5 cm/s`；任一新帧不满足会清空整段验证。
- 必须连续满足至少 `800 ms`，且至少有 `12` 帧有效观测，才进入 `TASK_HOLD` 并保持该时刻的电机倾角。
- 视觉未更新或被观测器判为异常时不会推进保持计时。
- `+5 cm` 的控制、制动和保持路径未修改。
