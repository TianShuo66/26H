# 0055 - 延后负五厘米近端制动

日期：2026-08-01

## 实测依据

在 `0 -> +5 -> -5 cm` 日志中，正向过程达到 `+5 cm` 正常。负向过程中：

- `X=-3.0 cm` 左右已进入近端制动；
- 输出强制为 `TILT_REF=-70`；
- 钢球在约 `-3.6 ~ -3.7 cm` 就停止并折返，未到 `-5 cm`。

## 修改内容

- `TASK_NEGATIVE_CAPTURE_BRAKE_ZONE_DECI_CM`：`20` 改为 `10`。
- 因此负向近端制动由距目标 `2.0 cm` 改为距目标 `1.0 cm` 才介入，预计从 `X=-3.0 cm` 后移至约 `X=-4.0 cm`。

## 未修改内容

- `0 -> +5 cm` 的全部控制与制动参数未改动。
- 负向的外环、速度环、静摩擦补偿、电机速度和加速度未改动。
- `-5 cm +/-0.7 cm` 连续 `800 ms` 的保持判定未改动。
