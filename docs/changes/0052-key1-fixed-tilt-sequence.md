# 0052 - Key1 固定倾角任务序列

日期：2026-08-01

## 修改内容

Key1 的任务运动改为固定倾角、视觉切相位的序列：

1. 从中心点以 `-65 pulse` 推动钢球向 `+5 cm`。
2. 视觉到达 `+3.1 cm` 后固定为 `+70 pulse` 制动。
3. 视觉达到 `+4.8 cm`（`+5 cm` 的确认容差）后，继续保持 `+70 pulse`，推动钢球向 `-5 cm`。
4. 视觉到达 `-4.2 cm` 后固定为 `-70 pulse` 制动。
5. 进入 `-5 cm +/-0.7 cm` 后，连续 `800 ms` 位于范围内即冻结当前电机倾角。

## 参数来源

- `-65 pulse`、`+70 pulse` 来自 2026-08-01 的三次串口实测：右向起步使用约 `-65 pulse`，`X=+3.1 cm` 后使用 `+70 pulse` 可到达 `+5 cm` 附近。
- 旧逻辑在 `X=-3.0 cm` 就使用 `-70 pulse`，三次运行均只到 `-3.6 ~ -3.7 cm`；因此固定负向制动起点后移到 `-4.2 cm`。

## 未修改内容

- Key2 回中心仍为原有闭环控制。
- Key3、Key4 的单目标闭环控制未改动。
- 电机速度、加速度、机械零点和软限位未改动。
