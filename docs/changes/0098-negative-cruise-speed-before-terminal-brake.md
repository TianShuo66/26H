# 0098 - 负向提前维持巡航驱动力

## 问题

- 负向速度参考此前随距离 `-6 cm` 缩短而立即下降，钢球尚在 `-2 ~ -4 cm` 时已经开始明显减速。
- 最新测试中，折返发生在约 `2910 ms`，在 `5000 ms` 总时限内无法在减速后继续到达 `-6 cm`。

## 修改

- 新增负向巡航速度规则：在距 `-6 cm` 仍超过 `2 cm` 时，将实际 `VREF` 限制为不高于 `-8 cm/s`，避免过早制动。
- 进入最后 `2 cm` 后，取消巡航下限，恢复原有位置-速度闭环减速、末段微调和稳定保持。
- 串口 `VREF` 改为输出实际参与控制的速度参考值。
- `0 -> +5 cm`、中心点、机械零点与电机速度参数不变。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过。
