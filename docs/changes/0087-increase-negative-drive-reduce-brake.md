# 0087 - 增强负向推进并减弱反制动

## 依据

最近一次测试中，钢球在 `X=-3.1 cm`、速度约 `-5.1 cm/s` 时已触发约 `-41 pulse` 的反制动，最终在 `-3.3 cm` 附近转向，未到达目标。负向自适应推进同时已达到 `75 pulse` 上限。

## 修改

- 仅调整 `+5 -> -5 cm` 的参数，`0 -> +5 cm` 不变。
- 负向最小推进倾角由 `35` 提升至 `45 pulse`，上限由 `75` 提升至 `100 pulse`。
- 负向反制动起始倾角由 `20` 降至 `12 pulse`，上限由 `70` 降至 `50 pulse`。
- 反制动仍由实时视觉速度触发，不使用固定时间或固定位置序列。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过。
