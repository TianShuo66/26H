# 0050 - 分离中心点与负五厘米控制参数

日期：2026-08-01

## 修改内容

- 将运行控制参数整理为三个独立配置：中心点、`-5 cm`、`+5 cm`。
- 中心点与 `-5 cm` 现在分别拥有独立的：位置外环、速度环、微调范围、静摩擦补偿、近端制动参数。
- `-5 cm` 的保持误差和验证时间也改为独立命名。
- 配置按目标位置选择，直接设定 `-5 cm` 目标时同样会使用 `-5 cm` 参数。

## 当前数值

- 中心点和 `-5 cm` 的新配置初始数值与此前共用参数完全一致。
- 此次仅完成参数解耦，不在缺少新的 `-5 cm` 实测日志时猜测改变增益。
- `+5 cm` 沿用此前已验证的全部数值和分支逻辑。
