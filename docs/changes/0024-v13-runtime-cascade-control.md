# 引入 V13 运行时级联控制算法

- 代码提交：本文件所在提交
- 日期：2026-07-31

## 范围

- 仅借鉴 V13 的运行时视觉观测与闭环控制算法。
- 保持当前工程的机械水平零点、相对位置电机命令、按键定义、驱动速度/加速度和软件行程限位不变。

## 修改内容

- 视觉位置估计改为 alpha-beta 观测器：位置系数 0.65、速度系数 0.10、残差门限 2.5cm、最大估计速度 `+/-30 cm/s`。
- 视觉帧间隔超过 200ms 时重置观测器；连续 3 帧异常测量时使用当前测量重新初始化。
- 位置外环按 `VREF = clamp(1.3 * position_error, +/-10 cm/s)` 生成期望速度。
- 速度内环按 `TILT = 4.5 * (velocity - VREF)` 生成倾角目标，继续通过既有相对位置小步命令跟随。
- 移除微调区 `+/-24` 脉冲强制限幅和固定短脉冲起步逻辑，避免进入 `+/-1.5 cm` 后无法继续向目标运动。
- 新增自适应静摩擦最小倾角：初值 15 脉冲，低速且误差超过任务完成范围时每 250ms 加 5 脉冲，最大 150 脉冲；检测到明显运动后逐步回落。
- `CONTROL` 串口行新增 `VREF` 与 `ADAPT` 字段，单位分别为 `0.1 cm/s` 和脉冲。
