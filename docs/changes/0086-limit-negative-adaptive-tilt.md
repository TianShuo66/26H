# 0086 - 限制 -5 cm 自适应推进上限

## 问题

负向低速推进增强后，自适应倾角在中段累加到 `135 pulse`。当钢球接近 `-5 cm` 时，实时控制虽然已发出负向制动目标，但电机仍需从大正倾角跨越到负倾角，实际摆杆来不及翻转，钢球越过 `-5 cm` 后继续冲到约 `-10 cm`。

## 修改

- 仅将负向自适应推进上限由 `150` 限制为 `75 pulse`。
- 保留 `35 pulse` 的最小推进、快速递增与实时速度反制动。
- 较小的最大正倾角缩短了电机由推进切换到反制动的实际行程，避免制动指令到达时摆杆仍保持大推进倾角。
- `0 -> +5 cm` 的控制代码和参数不变。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过。
