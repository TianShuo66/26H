# 终端区限倾角制动

- 代码提交：本文件所在提交（提交说明：`Use terminal-zone braking control`）
- 日期：2026-07-31

## 输入日志结论

`REF,+5.0` 任务中，钢球在约 `+2.0 cm` 时已经出现 `STOP_DIST=2.8 cm`、`PRED_ERR=0.2 cm`，控制器过早回摆，最终只到约 `+3.5 cm`。后续的大倾角反向又将钢球拉回，无法在目的地附近稳定。

## 修改内容

- 距离目标超过 `2 cm` 时，控制器只按位置和速度阻尼推进，不使用停车距离预测。
- 距离目标进入 `2 cm` 后才启用预测制动。
- 在该终端区内，将摆杆目标限制为 `±80` 脉冲；远端推进仍可使用 `±160` 脉冲。

这样远距离有足够推进力，近目标时不再用大倾角反复加速钢球。
