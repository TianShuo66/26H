# 0144 - 增加 KEY3 的安全倾角余量

## 修改原因

KEY3 的 `+7 cm` 任务中，钢球停在约 `X=2.4 cm`，电机已达到约 `-130 pulse`。机械极限反馈位置为 `RAW=-5974`，以当前机械零点 `RAW=-2714` 换算约为 `-159 pulse`，原 KEY3 与 KEY2 共用的 `150 pulse` 自适应上限未使用全部可用行程。

## 修改内容

- 为 KEY3 建立独立控制参数。
- KEY3 自适应倾角上限从 `150 pulse` 增至 `155 pulse`。
- 保留约 `4 pulse` 的机械行程余量，不触及 `-5974` 的已知极限。
- KEY1 与 KEY2 的控制参数保持不变。

## 验证

- Keil 全量编译：`0 Error(s), 0 Warning(s)`。
