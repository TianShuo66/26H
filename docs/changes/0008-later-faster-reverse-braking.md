# 延后预测制动并加快反制动执行

- 代码提交：本文件所在提交（提交说明：`Delay prediction and speed reverse braking`）
- 日期：2026-07-31

## 问题

上一版预测停车距离过大，反向倾角进入过早；同时方向翻转后的短脉冲仍按普通运动速度发送。

## 修改内容

- 模型制动加速度由 `24/12` 调整为 `36/18`，单位为 `0.1 cm/s^2`。预测停车距离随之缩小，使制动晚于上一版介入。
- 普通短脉冲维持 `1000 RPM`、加减速参数 `100`。
- 检测到电机指令方向翻转时，先执行停止，再用 `1800 RPM`、加减速参数 `200` 发出反制动短脉冲。
- 仅反向制动使用高速参数，正常加速、保持和数据采集不受影响。
