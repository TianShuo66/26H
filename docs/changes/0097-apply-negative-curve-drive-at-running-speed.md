# 0097 - 负向卡滞区运行中保持推进

## 问题

- 最新日志中，钢球在 `-2 ~ -4 cm` 曲率区仍以 `4 ~ 8 cm/s` 向负方向运行。
- 原补偿仅在速度不超过 `1.5 cm/s` 时生效，因此控制器先将钢球减速；补偿在任务结束前约 `80 ms` 才开始，无法帮助钢球通过该区。

## 修改

- 将 `TASK_NEGATIVE_CURVE_COMPENSATION_SPEED_DECI_CM_S` 从 `15` 提高到 `80`，即卡滞区补偿在速度不超过 `8 cm/s` 时均生效。
- `+35 pulse` 的补偿范围仍严格限定为 KEY1 负向阶段的 `-2 ~ -4 cm`。
- 离开 `-4 cm` 后仍由既有位置-速度闭环执行减速与最终稳定保持。
- `0 -> +5 cm`、中心点和 `-6 cm` 末段参数不变。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过。
