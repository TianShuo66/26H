# 0067 - 拟合视觉 X 比例和零点

日期：2026-08-01

## 标定数据

机械刻度位置与当前视觉输出：

| 物理位置 | 当前视觉 X |
| --- | --- |
| `-5.0 cm` | `-4.8 cm` |
| `0.0 cm` | `0.2 cm` |
| `+5.0 cm` | `5.3 cm` |

## 修改

三点数据表明除零点偏置外，还存在约 `1%` 的比例误差。视觉 X 改为固定仿射校正：

```text
校正X = (当前X - 0.25) / 1.01
```

使用定点整数计算并按 `0.1 cm` 四舍五入。上述三点将分别映射为 `-5.0 cm`、`0.0 cm`、`+5.0 cm`。
