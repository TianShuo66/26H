# 降低 +5cm 端点制动补偿

- 代码提交：本文件所在提交（提交说明：`Reduce positive endpoint braking`）
- 日期：2026-07-31

## 修改内容

- 正向靠近 `+5 cm` 时，速度反馈增益从 `45` 降至 `30`。
- 其余方向和远离目标时仍保留原速度反馈增益，避免影响回收与负向控制。
- `+/-2 cm` 微调区及其 `+/-24` 脉冲倾角上限不变。

这会让 `+5 cm` 前的制动更晚、幅度更小，而目标附近仍由微调闭环收敛。
