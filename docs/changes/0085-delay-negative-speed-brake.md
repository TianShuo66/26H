# 0085 - 延后 -5 cm 高速反制动

## 问题

增强负向推进后，钢球已能越过 `-3 cm`。但在 `X=-2.6 cm`、速度约 `-10.3 cm/s` 时，速度扩展制动区已触发 `-70 pulse` 反制动；钢球在 `-4.1 cm` 便反向，距离目标仍约 `0.9 cm`，随后发生大幅回摆。

## 修改

- 仅缩小负向速度相关的制动区提前量。
- 速度扩展项从 `速度 / 10` 改为 `速度 / 50`，最大制动区由 `3.5 cm` 收缩到 `2.2 cm`。
- 保留 `0084` 的负向低速推进力度与反制动最大倾角 `70 pulse`。
- `0 -> +5 cm` 的控制代码和参数不变。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过。
