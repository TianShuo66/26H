# 0131 - 负向终点提前制动

## 修改

- 负向目标捕获制动区从最后 `0.5 cm` 扩大为最后 `1.5 cm`。
- 负向目标的制动强度独立设置为：基础 `35 pulse`、速度增益 `2`、上限 `54 pulse`。

## 原因

测试中钢球第一次接近负向目标时，速度约为 `-7.9 cm/s`。原逻辑直到距目标 `0.5 cm` 才以最多 `25 pulse` 制动，无法在第一次到达时消掉动量，必然回弹。

## 影响

- 负向目标根据当前速度提前反向制动，目标是在第一次到达 `-5 cm` 附近时直接停住。
- 不改动 `0 -> +5 cm`、中心点或 KEY3 控制参数。
