# 0101 - 加快回中心并隔离 KEY1 负向参数

## 问题

- 钢球视觉识别正常，但回中心任务对偏离和低速卡滞的响应不足，无法及时回到 `X=0`。
- 原中心点与 KEY1 的 `-6 cm` 负向段共用控制参数，直接提高中心增益会改变已验证的 KEY1 行为。

## 修改

- 新增独立的 `task_negative_control_parameters`，保留 `-6 cm` 原有的位置环、速度环、低速起步和末段微调参数。
- 仅提高中心任务的响应：位置增益 `1.3 -> 2.0`、速度环增益 `0.45 -> 0.65`、速度参考上限 `10 -> 12 cm/s`。
- 中心低速起步补偿改为 `25 pulse` 起步、每 `80 ms` 增加 `10 pulse`；最后 `1.5 cm` 的倾角上限提高到 `32 pulse`。
- 负向 `-6 cm` 继续使用原 `18 pulse` 末段限制和原低速补偿，不受中心点调参影响。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过。
