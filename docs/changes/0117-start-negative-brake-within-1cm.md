# 0117 - -5 cm 制动改为距目标 1 cm 内触发

## 原因

- -5 cm 末段捕获反制动原先在距目标 `2.0 cm` 内触发，因此钢球运动到约 `-3 cm` 时就开始制动。
- 仅降低制动上限无法改变提前制动的位置。

## 修改

- -5 cm 的末段捕获反制动触发范围从距目标 `2.0 cm` 缩小到 `1.0 cm`。
- 最大反制动保持 `25 pulse`，因此钢球通过 `-3 cm` 后才会在接近 -5 cm 时制动。

## 不变项

- 中心点不使用末段捕获反制动。
- +5 cm 使用独立的制动范围和参数，不受影响。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过，`0 Error(s), 0 Warning(s)`。
