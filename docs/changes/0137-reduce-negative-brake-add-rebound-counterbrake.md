# 0137 - 降低负向制动并增加回弹反制动

## 修改原因

负向终点制动锁存虽然避免了过目标后立即撤销制动，但制动角度过大，钢球会被推回正方向并滚回约 `-3 cm`。

## 修改内容

- 将 KEY1 负向终点制动从 `35~54 pulse` 下调为 `25~42 pulse`。
- 制动后速度降至零时进入反制动阶段。
- 若钢球仍在 `-5 cm` 右侧，则施加 `+30~45 pulse` 的反制动，阻止其继续向正方向回弹，并使其重新靠近 `-5 cm`。
- 正向 `0 -> +5 cm` 控制保持不变。

## 验证

- Keil 全量编译：`0 Error(s), 0 Warning(s)`。
