# 0064 - 校正视觉 X 坐标零点

日期：2026-08-01

## 标定依据

平面调平后，钢球放在机械中心 O 时，视觉串口原始坐标为 `B,-102,y`，即 `X=-10.2 cm`。

## 修改

- 在视觉帧解析处加入固定偏置 `VISION_X_ZERO_OFFSET_DECI_CM = -102`。
- 闭环使用的坐标按 `校正X = 原始X - (-102)` 计算。
- 因此原始帧 `B,-102,y` 会输出并参与控制为 `X=0.0 cm`。

## 未修改

- 电机机械零点、位置换算、速度和加速度未修改。
- `+5 cm`、中心、`-5 cm` 的控制参数及状态机逻辑未修改。
