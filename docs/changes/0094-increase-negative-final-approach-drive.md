# 0094 - 提高 KEY1 负向末段推进力

## 修改

- 将 `TASK_TO_NEGATIVE` 最后 `0.7 ~ 1.5 cm` 的低速静摩擦补偿从 `15 pulse` 提高到 `18 pulse`。
- 负向末段补偿改为独立参数 `TASK_NEGATIVE_FINE_STATIC_PULSES`，不再与中心点共用。
- 仅在钢球尚未到达 `-6 cm`、低速且位于末段微调区时增加推进力；到达误差范围后仍由速度闭环反制动。
- `0 -> +5 cm`、中心点控制、机械零点和电机运动参数不变。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过。
