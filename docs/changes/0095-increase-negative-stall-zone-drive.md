# 0095 - 提高负向低速卡滞区推进力

## 问题

- 串口记录显示，KEY1 从 `+5 cm` 返回时在 `X=-3.6 ~ -3.9 cm` 附近速度降至零，未进入 `-6 cm` 末段即因任务超时停止。
- 此位置属于已知的负向低速卡滞区，不是 `-6 cm` 的最终保持区。

## 修改

- 将低速卡滞区补偿从 `20 pulse` 提高到 `35 pulse`。
- 补偿仍只在 KEY1 负向阶段、位置约为 `-2 ~ -4 cm`，且钢球负向速度不超过 `1.5 cm/s` 时叠加。
- 不改变 `0 -> +5 cm`、中心点控制、`-6 cm` 末段补偿、机械零点及电机速度参数。

## 验证

- Keil `F407_STEP2_EmmV5` 全量编译通过。
