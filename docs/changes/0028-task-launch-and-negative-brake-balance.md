# 任务起步与 -5cm 制动分离调节

- 代码提交：本文件所在提交
- 日期：2026-07-31

## 日志结论

- KEY1 的首次 `REJECT_START_POSITION` 是起点未满足静止条件；后续 `TASK,START` 说明按键与任务状态机正常。
- `O -> +5cm` 启动后，`ADAPT=70` 仍未克服静摩擦，任务在 5 秒超时。
- `-5cm` 端的 120 脉冲保持制动过强，导致回摆幅度过大。

## 修改内容

- 仅在 `TASK_TO_POSITIVE` 的起步过程中，将自适应静摩擦补偿最大值提高到 120 脉冲；其他目标仍限制为 70 脉冲。
- 保留 `-5cm` 端提前 3.5cm 制动与保持式制动逻辑。
- 将 `-5cm` 端制动基础值和上限恢复为 35/70 脉冲，防止 120 脉冲制动产生过度反向加速度。
