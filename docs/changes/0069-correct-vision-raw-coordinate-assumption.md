# 0069 - 修正视觉原始坐标假设

日期：2026-08-01

## 问题

此前错误地将 `-10.2 cm` 当作视觉原始 X 坐标，因而在视觉解析中叠加了 `+10.2 cm` 固定偏置。

实际原始视觉 X 标定数据为：

| 物理位置 | 原始视觉 X |
| --- | --- |
| `-5.0 cm` | `-4.8 cm` |
| `0.0 cm` | `0.2 cm` |
| `+5.0 cm` | `5.3 cm` |

## 修改

- 删除错误的 `+10.2 cm` 固定偏置。
- 直接对原始 X 应用三点拟合关系：`校正X = (原始X - 0.25) / 1.01`。
- 原始 `0.2 / 5.3 / -4.8 cm` 现在分别校正为 `0 / +5 / -5 cm`。

## 未修改

- `-14.8°` 机械水平零点保持不变。
- 电机速度、加速度、闭环参数和按键逻辑未修改。
