# 0058 - 降低负二到零厘米的中心补偿

日期：2026-08-01

## 修改内容

- 中心点微调静摩擦补偿改为按钢球位于中心左侧或右侧分别配置。
- 钢球从左侧 `-2 -> 0 cm` 回归时，补偿使用 `20 pulse`。
- 钢球从右侧回归中心时，继续使用 `25 pulse`。

位置误差为正表示钢球处于中心左侧，因此代码使用 `position_error > 0` 选择较小的左侧补偿。

## 未修改内容

- `0 -> +5 cm` 与 `+5 -> -5 cm` 的全部参数未改动。
