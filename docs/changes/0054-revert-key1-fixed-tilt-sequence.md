# 0054 - 撤销 Key1 固定倾角任务

日期：2026-08-01

## 原因

固定倾角任务实测中，钢球先冲到 `+7.6 cm`，随后左向冲到 `-11.2 cm`。电机转向存在明显的实际跟随延迟，固定脉冲无法根据钢球速度及时减小或反向。

## 修改内容

- 删除 Key1 的固定相位和固定倾角覆盖。
- 恢复实时级联闭环：视觉位置生成期望速度，视觉速度与期望速度的误差生成电机倾角。
- 恢复原来的 `+4.5 cm` 折返条件与动态近端制动。

## 保留内容

- 中心点不进入稳定保持。
- 中心点、`-5 cm`、`+5 cm` 的控制参数仍独立。
- `-5 cm` 进入 `+/-0.7 cm` 后连续 `800 ms` 的保持判定仍有效。

## 回退

固定倾角版本对应提交：`92a44c9` 和 `090b240`。
